# Component datasheets (DMXRZ-S3)

This folder holds the **2.0″ LCD panel datasheet** and **selected component datasheets** for the **DMXRZ-S3** (Portable DMX512 & RDM Field Controller). Use these PDFs alongside the schematic and BOM in [`../easyeda/`](../easyeda/) when you need pinouts, electrical limits, or mechanical dimensions for key parts on the board.

本目录将存放显示屏及关键器件的数据手册（PDF），由 Kelvin 陆续补充。
