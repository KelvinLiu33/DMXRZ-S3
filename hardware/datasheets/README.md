# Component datasheets (DMXRZ-S3)

This folder holds the **2.0″ LCD** and **selected component datasheets** (PDF), plus the LCD **mechanical outline (DWG)**, for the **DMXRZ-S3** (Portable DMX512 & RDM Field Controller). Use them with the schematic and BOM in [`../easyeda/`](../easyeda/) when you need pinouts, electrical limits, or mechanical dimensions. Additional component datasheets may be added over time.

本目录存放显示屏及相关器件的数据手册（PDF）与结构图（DWG），与 [`../easyeda/`](../easyeda/) 中的原理图与 BOM 对照使用；其余器件手册可继续补充。
