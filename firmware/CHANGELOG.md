# Changelog

该 DMX/RDM/RZ 控制器项目的所有显著更改都记录在此文件中。

## [1.1.2] - 2026.10.11

### Added
-
### Changed
- RZ 时钟超出范围时改为保存 1 MHz，不再因此拒绝线制，也不因此重建灯带
- 只有线制或灯珠数变化时才重建灯带
- 只有 DMX 口发送成功才开始计算信号丢失
### Fixed
- 修复离开调色后，输出目标仍是 RZ Code 或 DMX + RZ 时灯带驱动被关掉
- 修复只走灯带时把 DMX 误判成信号丢失

## [1.1.1] - 2026.10.11

### Added
- 未激活时增加激活串口，编号 303A:4002，名称 DMXRZ Activate；不烧 eFuse，激活后该口关闭
- 一键激活工具自动等待并识别激活串口
- 升级必须使用已签名程序；无签名程序拒绝写入
- 未激活时关闭 RDM、Art-Net、WEB、OTA；DMX、RZ、调色、语言、背光保持可用
### Changed
- 未激活页二维码加大，屏上不再单独显示设备号
- WEB 连接局域网 IP 后直接打开，不需要登录
- 息屏后关闭触摸；按键或旋钮点亮后触摸恢复，摸黑屏不能唤醒
- 恢复出厂清除 Wi-Fi，保留授权证书
- 中文提示改为字库中已有的标点
- 离开调色时先输出黑场
- 帮助二维码在 WEB 未授权时不显示网址
- 开机遇到无效的输出来源、输出目标或丢失动作时改为回退，不再停机
### Fixed
- 修复 RDM 扫描中途低电量退出后，已发现设备保持静音
- 修复屏幕调色和 WEB 调色同时占用时互相解除占用
- 修复未激活时仍然回应 Art-Net Poll
