# mechanical

3D-printable enclosure and mechanical parts (STL / related files) for the Tindie product.

- Hardware rev **1.5** (match files to the shipping unit when multiple revs exist).
- Published as **reference / spare-part** files for buyers — not a DIY build kit.
- Prefer one clear filename per part (e.g. `top-shell.stl`, `bottom-shell.stl`).

Do not put signing keys or other secrets here.
